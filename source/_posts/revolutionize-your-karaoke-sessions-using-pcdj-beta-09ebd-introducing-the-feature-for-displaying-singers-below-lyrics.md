## Revolutionize Your Karaoke Sessions Using PCDJ Beta 0.9.ebd - Introducing the Feature for Displaying Singers Below Lyrics!

[![Karaoki Karaoke software singer scroll](https://i0.wp.com/pcdj.com/wp-content/uploads/2020/11/karaoki-scroll.jpg?resize=752%2C321&ssl=1)](https://i0.wp.com/pcdj.com/wp-content/uploads/2020/11/karaoki-scroll.jpg?fit=752%2C476&ssl=1 "Karaoki Karaoke software singer scroll")

**Karaoki public beta 0.9.7619 is available for download! In this new release KJs can display the singer scroll below the lyrics on the secondary singer screen.**

Karaoki beta version 0.9.7619 can be downloaded and installed below. The prior Karaoki public beta introduced a few new news ticket/scroll feature, and version 0.9.7619 adds some polish and includes the enhanced ability to display a list of your upcoming singers below the lyrics on the singer screen (screen 2). When the news ticker/scroll is used beneath the CDG/Video graphics output, using the “CDG transparency” mode with a fairly plain background image and a 2% border around the video, things begin to look slick!
