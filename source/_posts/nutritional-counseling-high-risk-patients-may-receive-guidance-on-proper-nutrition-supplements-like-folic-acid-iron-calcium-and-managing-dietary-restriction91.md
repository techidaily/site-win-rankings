**Download public beta version 3.10.0.3 of DEX 3 Pro below!**

A new public beta version 3.10.0.3 of DEX 3 Pro has been made available for download. Largely a maintenance release of our [**best DJ Software**](https://tools.techidaily.com/pcdj/products/), the 3.10.0.3 tuneup includes a slathering of performance improvements and bug fixes, most notably and issue with loading certain zip files (karaoke mp3+G zips) that would cause the player to be un-responsive until restarted.

![DEX 3 video mixing and DJ software](https://i2.wp.com/pcdj.com/wp-content/uploads/2018/03/b760648c-043f-4f43-9db6-f8f0d0366f99.png?fit=300%2C186&ssl=1 "DEX 3 video mixing and DJ software")

On the flip side we’ve included support for three new and popular [DJ controllers](https://tools.techidaily.com/pcdj/products/) from Pioneer DJ; the **DDJ-SB3**, **DDJ-SR2**, and the **DDJ-WeGO4**. Native support for all three DJ controllers means DEX 3 Pro users are no longer required to download a map file for DEX 3 Pro support. They are now plug-and-play so you can jump into the mix straight away!

Due to popular request, we’ve also added a setting under the General tab in options “Use sync-lock when possible”. When this is not ticked in options DEX 3 Pro will revert to the older (original) sync method and not use the “Beat lock” technology.

_Remember_, this is a public beta, so while we’ve testing a bunch with our in-house team and beta testers we could use your additional help testing and reporting. So, feel free to download the DEX 3 Pro version 3.10.0.3 below and install over-top your existing installed version and if you have any issues to report, you can add them to the comments section at the bottom of this page.

_**Happy mixing! #MixEverything**_

#### All Changes Included In DEX 3.10.0.3 (Public Beta)

* Added new setting “Use sync-lock when possible”; if you disable it you get the old Sync functionality
* New controllers added: Pioneer DDJ-WeGO4, Pioneer DDJ-SR2, Pioneer DDJ-SB3
* Fixed deck getting “stuck” (playing only silence) after loading a bad karaoke zip file (eg. the files inside with different names)
* Various under-the-hood performance improvements
