## Learn Efficient Mixing Strategies with the DEX 3.3 Playlist Feature - Music Production Guide

[![](https://i0.wp.com/pcdj.com/wp-content/uploads/2015/01/multitrack-coverimage.jpg?resize=530%2C298&ssl=1)](https://i0.wp.com/pcdj.com/wp-content/uploads/2015/01/multitrack-coverimage.jpg?fit=530%2C298&ssl=1 "multitrack-coverimage")

**Our [DEX 3.3 DJ software update](https://tools.techidaily.com/pcdj/products/)dropped yesterday and introduced a few new features, but none more useful than multi-track selection.**

First off, _as I’m sure some are wondering why multi-track selection is new to DEX 3.3_, an explanation: DEX 3 is all custom code, designed by our development team. It doesn’t utilize built in functions/features of the OS you’re running the software on. Meaning, we don’t use the built in _“shift select”_ and _“ctrl select”_ functions provided in Windows or MAC.

[![](https://i1.wp.com/pcdj.com/wp-content/uploads/2015/01/dex33-blogcoverimage-template.jpg?fit=300%2C169&ssl=1 "dex33-blogcoverimage-template")](https://tools.techidaily.com/pcdj/products/)

_Why, you ask?_ The reason behind this provides a glimpse into our product line future — the code used for our best DJ software will deploy to any OS, and use the same assets. This simply means the future tablet version will work the same as the MAC or Windows version – the browser/library is already very touch-screen friendly, and will work just like it does in the new DEX 3.3 update. It also means we’ll be able to release updates across all platforms almost simultaneously, providing speedier updates and if something isn’t working as expected – we can fix it across all platforms at once.

I hope that helps you realize where we’re taking PCDJ and DEX 3.

In the video below we show you how to use the new “_Multi-Track Selection_” feature combined with the sidelist to create playlists. You build your list using the sidelist, and then move to your target playlist so it’s saved permanently.
